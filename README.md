# Smart Calculator (Tkinter)

## Overview
A sleek, modern GUI-based calculator built with Python's Tkinter library. It provides a user-friendly interface for performing basic arithmetic operations with a professional "Dark Mode" aesthetic.

## Key Features
- **Core Operations**: Addition, Subtraction, Multiplication, Division, and Percentage.
- **Input Management**: Features a clear (C) button and a backspace (⌫) button for error correction.
- **Modern UI**: Styled with a dark theme, custom button colors, and responsive layouts.
- **Error Handling**: Built-in protection against division by zero and invalid mathematical expressions.
- **Interactive Feedback**: Visual button hover effects and active states.

## Tech Stack
- **Language**: Python
- **GUI Framework**: Tkinter
- **Logic**: Python `eval()` with safety checks

## Setup Instructions
1. Ensure Python 3.x is installed.
2. No external dependencies are required (Tkinter is included in standard Python).
3. Run the calculator:
   ```bash
   python calculator.py
   ```
